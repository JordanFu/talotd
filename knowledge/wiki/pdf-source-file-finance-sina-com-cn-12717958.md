# 泰晶员工持股草案：内部流动与退出权益分开处理

## 一句话判断

员工持股是否值得参与，不能只看折价和预期收益，还要看出资、资金锁定及不同离岗情形的处置；草案不等于已经实施。

## 核心内容

- 正常内部职务变动延续计划；辞职及公司裁员者未解锁权益按对应原始出资收回。履职致丧失劳动能力与其他原因分开，前者个人绩效不再作为解锁条件。
- 员工自筹、风险自担；需股东会批准，不证明过户、收回或留任效果，也不是收益保证。

## 你需要关注

- HR与激励团队可在参与前提供调岗、辞职、裁员与退休算例，说明员工资金占用与退出条件，让员工自愿判断。
- 条款清楚不等于公平或有效；公司采用类似安排前须另核适用规则、员工承担的风险及争议处理。
