## 1. 今日一句话专题判断

**今天的证据没有支持“优秀伙伴随时永久晋升”，反而说明绩效评价、绩效加薪和职业通道必须分阶段、分责任、分预算治理：贡献可以持续识别，阶段回报可以及时发生，但永久职级仍应以固定窗口的横向校准为主，只为持续职责错配保留窄例外。**

### 读者应该带走什么

| 关键问题 | 今日答案 | 管理含义 |
|---|---|---|
| 绩效系统上线，是否等于晋升制度已经建立？ | 不等于。路易斯维尔大学的评价推广、绩效加薪和职业阶梯分处不同阶段 | 每项制度分别写清批准人、预算、时间、员工更正与申诉入口 |
| “3＝达到岗位要求”能否自动映射晋升？ | 不能。它只解释当前岗位评价档位，不是目标职级标准 | 绩效与晋升可以共享事实，但必须分开提问、评审和告知 |
| 是否应取消固定窗口，改为随时晋升？ | 今日没有新制度或后效支持；更稳妥的是即时回报、固定换级、窄例外 | 先解决长期无偿承担高一级责任，再讨论周期外永久职级 |
| AI贡献怎样进入晋升？ | 看人的判断、质量、风险、复用、团队赋能与净负担，不看工具活动量 | 不收私人对话、提示词、在线时长或黑箱总分，不增加举证型日报 |
| 职业阶梯计划能否当留任承诺？ | 不能；计划预计在2028财年推出且受预算约束 | 把“已批准、暂定、示例、待预算”分别沟通，避免制造隐性承诺 |

**三句话收束：**第一，今天新增的是一个分阶段的人力制度计划，不是一套已运行的晋升制度。第二，绩效、加薪、岗位价值与晋升必须共享事实但分别裁决；一个评分、一个项目或一张证书不能自动换职级。第三，未来晋升的核心不是收集更多个人数据，而是让真实工作证据可核、机会可比、决定可解释、错误可更正、收益可分享。

**管理层该问的问题：**我们是否把当前岗位绩效、市场调薪、项目奖励和永久晋升混成了一个决定？谁获得了高影响项目、导师、工具和正常工时内的学习机会，谁没有？员工持续承担高一级责任时，谁负责在常规窗口前纠偏并补偿？任何AI辅助证据，员工能否查看来源、补充反证、要求人工复核和申诉？

**不要误读：**路易斯维尔大学尚未实施职业阶梯，2.5%的涨薪池只是比较方案的例子；Qualcomm减员报道是单链退出线索，不是晋升制度；isolved的批准日志是薪资产品设计，不是人才委员会；Lightcast可回溯市场报告，不代表AI可以定级定薪；工具上线、培训结业、技能徽章或高AI使用量都不能直接证明下一职级胜任。

### 2.1 日期级Context｜路易斯维尔大学把评价、加薪与职业阶梯分阶段推进

1. Workday员工评价计划于 **2026年12月** 在全校推广；五级评价中，“3”表示达到当前岗位要求。
2. 绩效加薪暂定于 **2027年春** 推进，但分配方案尚未决定；答疑中的 **2.5%** 涨薪池只是比较方法的示例，不是最终预算或个人承诺。

4. 这些动作所处阶段不同：评价是计划推广，绩效加薪是暂定安排，职业阶梯是更晚期且依赖预算的计划。

## 3. 今日核心判断

### 判断一：分阶段推进能降低误解，但必须同时公开“已决定、暂定、示例、待预算”

- **可信度：高（事实解释）；公平与留任后效未知。**
- **证据基础：**路易斯维尔大学把2026年评价、2027年暂定绩效加薪和2028财年预算依赖的职业阶梯分开披露；2.5%只作示例。
- **为什么重要：**员工会据制度沟通安排职业和家庭决策。若把计划写成承诺、把例子写成个人预期，即使以后按程序修改，也会造成信任损失。每个阶段都应有具名负责人、批准点、变更通知和员工求助入口。

### 判断二：绩效、晋升与薪酬应“共享已核事实，分开回答问题、分开裁决”

- **可信度：高（治理判断）；今日没有运行后效。**
- **证据基础：**“3＝达到当前岗位要求”与未来职业阶梯并列但不等同；绩效加薪方案仍未决定。Qualcomm线索又表明绩效、岗位需要和业务选择容易被混写。
- **为什么重要：**绩效回答“当前责任完成得怎样”；晋升回答“是否持续承担下一职级且组织需要该岗位”；薪酬回答“同岗公平、市场价格与预算如何”。高绩效可以不升职，市场调薪可以不改头衔，岗位取消也不能倒推个人失职。

### 判断三：连续识别不等于连续换级；更稳妥的是“四只时钟”

- **可信度：中高；今日无新制度推翻历史基线。**
- **证据基础：**今日完整制度和比较后效均为0；路易斯维尔案例显示关键人力动作本就处在不同时间表。内部GitLab历史手册提供半年度校准、持续下一职级表现、业务需要和窄例外的制度参照，但不证明普遍最优。
- **为什么重要：**若所有贡献都等固定窗口，员工可能长期无偿承担更高责任；若一次项目就永久升职，则会放大项目曝光、主管关系和预算差异。应把持续取证、即时可逆回报、永久职级校准和明显错配例外分别治理。

### 判断四：AI贡献必须测“人的判断与净价值”，不得测“工具服从度”

- **可信度：高（风险判断）；AI晋升制度后效为0。**
- **证据基础：**当窗工具材料最多说明批准、日志和来源追溯，没有证据证明调用量、在线时长、提示词数或自动化率能预测下一职级胜任。
- **为什么重要：**只有员工先从工具中得到明确价值，才会自愿产生较可信的工作证据。若数据主要用于考核、减编或加任务，员工会减少披露、迎合指标或把私人工作迁出系统。AI证据应来自已授权工作流程，记录问题、人的判断、核验、质量、失败、复用和团队赋能，不收私人对话或细粒度活动轨迹。

### 判断五：晋升公平必须审“机会分母”，不能只校准最后一批候选人

- **可信度：中高（基于连续证据与反例）；今日无群体后效。**
- **证据基础：**今日没有任何材料披露谁获得高影响项目、导师、带薪学习、工具和提名；职业阶梯又受预算约束。资格看似统一，前置机会仍可能不均。
- **为什么重要：**如果少数人先得到关键项目，再以项目影响力选晋升，人才委员会只比较候选材料会把机会差异固化为能力差异。至少要看获得关键机会者、符合资格者、被提名者、自荐者、入评审者、晋升者和申诉改判者的分母及群体差异。

## 4. 重点案例事实还原：路易斯维尔大学的三阶段计划（日期级Context）

### 4.1 背景与时间线

- **2026-10-19：**校方举行公开答疑，讨论员工评价、绩效加薪和职业阶梯。
- **2026-10-20：**校方发布报道；原页缺分钟级时间，因此本轮不计严格窗口事实根。
- **2026年12月（计划）：**全校推广Workday员工评价。
- **2027年春（暂定）：**推进绩效加薪，分配方式仍未决定。
- **2028财年（预计）：**推出职业阶梯，受预算约束。

### 4.2 动作与机制

| 制度动作 | 已公开内容 | 尚未公开、不能推断 |
|---|---|---|
| 当前岗位评价 | 五级评价；3表示达到岗位要求；计划全校推广 | 评分一致性、经理训练、复核率、群体差异和员工体验 |
| 绩效加薪 | 暂定2027年春；分配方案未定 | 预算总额、公式、个人比例、绩效权重、薪酬公平检查 |
| 职业阶梯 | 预计2028财年推出；依赖预算 | 层级、族群、资格、证据、评审、晋升窗口、薪酬和申诉 |
| 沟通 | 公开答疑并区分计划与示例 | 后续书面规则、变更通知、个人反馈和改判流程 |

### 4.3 结果、争议与阻碍

- **结果：**目前只能确认分阶段计划和评价档位解释；没有职业阶梯已经运行、员工已晋升、薪酬已调整或公平改善的结果。
- **争议：**“达到岗位要求”容易被员工理解为“无发展”或“未达到晋升标准”，但公开材料没有给相邻层级的可观察差异与发展路径。
- **阻碍：**绩效加薪方案待定、职业阶梯受预算约束；大学治理、资金来源、员工类别和集体协商环境也不同于一般企业。
- **员工影响未知：**没有独立员工体验、评价纠错、申诉、薪酬压缩、不同群体结果或留任数据。

### 4.4 可借鉴点

1. 把评价、预算、调薪和职业通道拆开排期，不用一个“大改革”掩盖不同成熟度。
2. 公开解释“达到岗位要求”的含义，避免把正常达标污名化。
3. 对尚未批准的方案明确写“暂定”“示例”“受预算约束”，并设置后续更新时间。
4. 在职业阶梯上线前，先确定员工查看、补证、纠错、申诉和书面反馈机制。

### 4.5 不可照搬点

- 不把试点完成率当作评价准确、公平或员工受益；
- 不把绩效加薪当作晋升，不把职业阶梯开放当作自动晋升；
- 不用预算不足长期延迟对已持续承担高一级责任者的补偿；
- 不从美国大学的阶段安排直接推导企业的窗口、薪幅或法律操作；
- 不要求员工通过新增详细日报证明价值，优先复用已授权工作中的真实结果与复盘。

## 7. 对我们的行动启发

### 7.1 采用“四只时钟”，而不是在固定窗口与随时晋升之间二选一

1. **持续证据时钟：**从已授权工作中自然沉淀任务范围、难度、人的判断、质量、协作、风险和复盘，不新增详细日报或下班后举证。
2. **即时回报时钟：**项目里程碑后及时决定奖金、专项津贴、调休、署名、学习资源或下一个项目选择权；即时回报不自动改变永久职级。
3. **永久职级时钟：**季度或半年度由跨团队人才委员会校准，审下一职级责任是否持续、证据是否跨场景复现、组织是否有岗位需要、机会是否可比。
4. **窄例外时钟：**仅在责任和决策权已持续改变、等待会造成明显不公时周期外晋升；由业务、HR与薪酬共同书面批准，在下个窗口复核群体差异与一致性。

### 7.2 十一项机制的最小可行设计

| 机制 | 建议安排 | 人本与公平护栏 |
|---|---|---|
| 常规晋升窗口 | 公布资格、截止、评审、校准、生效和反馈日期 | 标准提前公开；结果逐项说明；设独立申诉期 |
| 即时／窗口外晋升 | 只处理持续职责错配；三方审批；下一窗口复核 | 不因外部报价、离职威胁或经理关系口头特批 |
| 项目制晋升／奖励 | 项目先形成奖金、津贴、调休和证据，不自动换级 | 记录谁获得关键项目；共同贡献不被负责人独占 |
| 岗位价值变化触发 | 先评责任范围、决策权、风险、持续期和岗位需要 | 先删旧任务或补资源；不得长期“无薪升责” |
| 能力认证 | 作为学习反馈或准入证据，需真实任务验证 | 正常工时学习；组织承担必要成本；提供替代证明路径 |
| 技能徽章 | 标明来源、范围、有效期和复证，员工可见可改 | 不按徽章数量排名；不从行为轨迹暗推永久标签 |
| AI贡献度评估 | 看问题价值、人的判断、核验、质量、风险、复用和团队赋能 | 不数调用、提示词、在线时长；不收私人对话；核净负担 |
| 同行评审 | 选择直接合作且无利益冲突者，允许异议和反证 | 防人气投票、互保与报复；员工知道意见如何使用 |
| 人才委员会 | 业务、HR、薪酬和跨团队评审者共同审标准、例外与机会分母 | 写出理由与责任人；小样本群体资料最小化；设二次复核 |
| 薪酬校准 | 分开同岗公平、市场修正、项目奖、代理津贴与晋升涨薪 | 检查薪酬压缩和追溯补偿；不用升职绕过调薪问题 |
| 绩效—晋升耦合／解耦 | 共享已核事实，分别决定当前绩效、永久职级和市场价格 | 一次高绩效不自动升职；未晋升不等于低绩效；分别申诉 |

### 7.3 用“三张决策单”避免一个分数包办所有高后果决定

- **绩效单：**当前岗位目标、质量、协作、风险与结果；解释“本周期做得怎样”。
- **晋升单：**目标职级责任是否持续、能否跨情境复现、组织是否有岗位需要；解释“是否应改变永久职级”。
- **薪酬单：**同岗公平、市场稀缺、地区、薪酬压缩、留任风险和预算；解释“怎样支付才合理”。

三张单可引用同一已核事实，但不得共用一个黑箱总分。每张单都要有具名决定人、书面理由、员工查看范围、纠错和申诉路径。

### 7.4 AI贡献证据包：只记录完成决定所需的最少事实

1. 问题与业务价值，员工原本需要完成什么；
2. 人的定义、判断、核验、升级与风险承担；
3. AI完成哪些步骤、失败在哪里、怎样恢复；
4. 质量、客户或业务结果、复用和团队赋能；
5. 是否真正减少返工、会议、等待和加班，还是增加维护与任务量；
6. 员工获得的工具、时间、导师和项目机会；
7. 数据来源、用途、访问、留存，以及员工补证、更正和申诉；
8. 节时与价值如何分配为调休、奖金、学习、团队容量、自主权或更高价值工作。

### 7.5 一个周期的试行方案

选择一个职责已被AI明显改变、且员工能获得明确好处的岗位族群，员工与岗位专家共同核对标准。先运行一个完整绩效／晋升周期，比较：证据准备时间、经理与委员会复核时间、机会获得率、晋升率、申诉率、改判率、薪酬变化、群体差异、晋升后表现、返工与加班。只有净负担下降、员工信任可维持、误差可纠正，才扩大范围；不要以系统使用量或报告数量作为成功标准。
